How it works

Every model is built on your device. The image never leaves the browser, and nothing is uploaded — projects live in localStorage.

Limits

  • Local storage is roughly 5 MB per site. A stored project is mostly its image, so expect 10–25 projects depending on size.
  • Geometry is never stored — a project is an image plus settings, and the model is rebuilt deterministically when you open it.
  • Clearing site data in your browser deletes every project. Export a GLB to keep a copy.
